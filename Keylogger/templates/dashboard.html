⚙️ How This Keylogger Works
  1. The Python script uses pynput to hook into the OS keyboard event stream at the driver level.
  2. Every key-press and key-release fires a callback that timestamps and records the key name.
  3. Events are appended to a plain-text and a JSON file on your Desktop in real time.
  4. A Flask web server reads those events from memory and serves them to this browser dashboard via a REST API.
  5. The browser polls /api/events every second and updates the UI — no page reload needed.
🛡️ How To Protect Yourself
🔍
Use Anti-Malware / EDREndpoint Detection tools flag unauthorized keyboard hooks. Tools like Malwarebytes or Windows Defender catch most keyloggers.
🔑
Use a Password ManagerAuto-fill bypasses keylogging because keys are never typed. Use Bitwarden, 1Password, or similar.
🖥️
Use Virtual Keyboards for Sensitive InputOn-screen keyboards use mouse clicks, not keyboard events — invisible to pynput-style loggers.
🔐
Enable 2FA / MFAEven if a password is captured, MFA prevents account takeover without the second factor.
📦
Keep OS & Apps UpdatedKeyloggers often exploit outdated drivers. Patches close these gaps quickly.
🚫
Don't Run Unknown ExecutablesMost keyloggers arrive as email attachments or pirated software. Only run trusted, signed software.
